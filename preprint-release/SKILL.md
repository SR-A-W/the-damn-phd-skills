# Preprint Release — 整理成预印版(arXiv 等)工作流

把一个 LaTeX 项目(通常是 Overleaf 仓)整理成 arXiv 上传 zip。核心事实:**arXiv 公开完整源码**——读者能看到每一行注释、每个文件名、每条 bib。所以这不是打包,是一次"源码即将公开"的安全清理。

## 调用形态

```
/preprint-release <论文仓路径> [可选:输出名/备注]
```

## 总流程(8 步,顺序执行,每步有验收)

### 1. 副本隔离(不可协商)
- `git pull` 拿最新 → 复制整个项目到独立工作目录(scratchpad),**正式仓一个字节不动**。
- 记下源 HEAD hash;最终验收之一 = 副本渲染与正式版渲染 `pdftotext` 逐字 diff = 0(内容零漂移的硬证据)。
- 先删:`.git`、`*.aux/log/out/blg/pdf`、README(仓库自述,非论文内容)、`__pycache__` 等。

### 2. 死文件与敏感文件名(在剥注释**之前**做,因为要看注释判断)
- 从主 tex 的 `\input`/`\include` 清单确定 **live 文件集**;未被引入的死章节文件(常含占位符、TBD、废稿)**整个删除**。
- **文件名审查**——文件名本身就是公开信息:
  - 暴露 AI 参与的名字(如 `gpt_formalization_problem.tex`)→ 改中性名(`formal_specification.tex`),同步改主 tex 的 `\input`;
  - 含个人名字的文件(`method_<somename>.tex`)→ 改中性名;
  - 改名后重编译确认无 missing file。
- **内部开发史注释/字符串**:代码级正文里若有 "V2 broken / 失效版 / fed to GPT-x" 类叙述(哪怕在将被保留的 live 文件里),改写为中性技术表述。

### 3. 注释全剥
- 用 **`arxiv-latex-cleaner`**(`pip install arxiv-latex-cleaner; python -m arxiv_latex_cleaner <dir>`)——它正确处理 `\%` 转义、verbatim 环境;**不要手写 regex 剥注释**(跨行色组、行尾 % 都是坑)。
- 验收:`grep -rn "^%"` 与行内注释抽查 = 0;审阅色标记、归档原文、蓝色旧稿等全部随注释消失。

### 4. bib 净化
- 从编译产物 `.bbl` 反查全部被引 key(`\bibitem[...]{key}`),用 brace-aware 解析从原 bib 抽出**仅被引条目**,重写 bib。草稿期未引条目(可能暴露放弃的方向)不外泄。
- **`.bbl` 和净化版 `.bib` 都要打包**:arXiv 编译认 `.bbl`(无需跑 bibtex),但作者常会把包丢回 Overleaf 验证——Overleaf 强制跑 BibTeX,没有 `.bib` 就全文引用爆炸(实战翻过车)。
- 断言:被引 key 在净化 bib 中 100% 命中,一条不缺。

### 5. 图与资源瘦身
- 重新扫描剥注释后的 live `\includegraphics`,只保留被引用的图文件(注释里引用的图已随注释死亡,常能砍掉 3/4)。
- 留意同名不同扩展名(`.png` vs `.pdf`)只保留被用的那个;检查非 figures 目录下的散图。

### 6. AI 痕迹与遗留占位终扫
- 清理后源码 + 渲染 PDF 双面扫:`chatgpt|claude|copilot|generated by|GPT-[0-9]|as an ai`(**合法引用条目/论文标题除外**,逐条分诊);
- 占位符扫:`TBD|XXX|\[X\.X\]|placeholder|lorem`;
- 若项目做过改名/换口径,旧名清单也扫一遍。
- (若装有 `paper-severe-issue-audit` skill,可直接对副本跑其八类扫描替代本步。)

### 7. 独立编译验证 → 打包
- 副本内完整循环:`pdflatex → bibtex → pdflatex ×2`;验收:**0 新增 error、页数与正式版一致、`[?]`=0、pdftotext 与正式版 diff=0**。
- 删除编译产物(pdf/aux/log/blg),`zip -rq` 打包。**渲染出的页要真的读几页**,不能只看退出码。

### 8. 提交页元数据把关(用户在 arXiv 网页操作,agent 出核对清单)
- **摘要纯文本化**:LaTeX 宏展开(自定义命令如 \think{} → 实际字符)、`---` 在 arXiv 摘要不渲染成破折号(手改为 " — " 或标点)、`\times`/× 写 x、`$...$` 数学 MathJax 可留但需预览确认;
- **分类字段**:MSC-class 是数学分类(68Txx 形态),`I.2.7` 这类是 **ACM-class**——别填错字段;CS 论文 MSC 通常留空;
- 作者列表与论文作者块逐一核对(人数、顺序、拼写);
- Comments 的页数/图数/表数与实际一致;
- **License 提醒**:CC BY 系不可撤销的宽松授权,arXiv 默认非独占 license 更保守——确认用户是知情选择;
- 预览页 PDF + HTML 双转换 Success 后再 Submit。

## 增量 re-pack(正式版又改了)
重新从最新 HEAD 走完整 8 步(脚本化后约 2 分钟)——**不要**在旧包上手工打补丁;每版 zip 带版本号(v1/v2/v3...),报告里写明基于哪个 HEAD。

## 事故档案(实战翻过的车,执行时自查)
1. **只打包 .bbl 不打包 .bib** → 用户丢回 Overleaf 验证时 BibTeX 报 "couldn't open database",全文引用变 undefined。两个都带。
2. **敏感信息在文件名而非文件内容里**(gpt_*.tex)——grep 内容扫不到,必须单独过一遍文件名清单。
3. **元数据字段错位**(ACM 分类填进 MSC-class)——提交预览页要整页截图级逐字段核对。
4. **摘要三连字符 `---` 原样显示**——arXiv 摘要是纯文本不是 LaTeX。
5. 匿名期遗留("anonymous snapshot"、"Notes for Reviewers"、Anonymous Authors 版权头)在 de-anonymize 后仍残留——公开前全仓扫 `anonym|reviewer`。
