# 海报黄金标准自检清单(会议无关)

交人审阅前,逐条执行并在 POSTER_STATE.md 记录结果。任何一条不过 → 改脚本重跑,不交。

## A. 画布与合规
- [ ] 画布尺寸 = 会议公布尺寸,或 = 官方/印刷商模板尺寸且已记录等比缩放系数(如 56→70 in = 1.25×)
- [ ] 会议对 logo/位置/颜色若有规定已满足;无规定则不臆造规定
- [ ] 场次信息(若放)与官网"会议当地时区"一致

## B. 字号(以 56 in 宽画布为基准;画布不同按宽度比例换算;印刷放大系数另算)
| 元素 | 范围 |
|---|---|
| 标题 | 60–66 pt(居中,≤2 行) |
| 作者行 / 机构行 | 28 / 22 pt |
| Section 标题 | 42–44 pt,主题色,带编号 |
| 正文段落 | 26–28 pt |
| 结论 bullet / callout | 28–32 pt |
| 图注 / 表注 | 20 pt,灰色斜体,"Figure N. / Table N." 前缀 |
| 表格 | 20–24 pt,表头反白,单元格**纵向居中** |
- [ ] 正文体与图注体明确两套样式,**不混用**(结论句不能长得像图注)
- [ ] 任何文本框在预览图中**无溢出红框**;字号调大后必须重跑预览

## C. 版面
- [ ] 所有面板有明显边框(≈3 pt);放图面板白底;文字面板浅底
- [ ] 正文结论 / takeaway 放在带底色 + 细边框的 callout 框内
- [ ] 每个面板留白 ≤ 15%;先把内容填满再匀空隙,不留"半页空"
- [ ] 面板间距一致(0.5–0.6 in),外边距一致(≈1 in)
- [ ] 阅读顺序清楚:section 编号 1..N,中心主视觉可不编号

## D. 图表
- [ ] 论文原图保持原宽高比,不拉伸
- [ ] 只裁行不裁轴:带状截图核对裁切线(x 轴标签完整、不露下一行 y 轴)
- [ ] 图内字号在印刷尺寸下可读;不行则重出或放大/减列
- [ ] 每图每表有图注;图注不复述正文结论

## E. Logo / 二维码
- [ ] 机构 logo 按**视觉重量**配平(粗体大字标缩小、堆叠小字标放大),同侧成组、垂直居中对齐
- [ ] 项目 logo 不放左上角;放主视觉旁或二维码区
- [ ] 全部 logo 透明底(预览里黑块 = 预览 bug,核 alpha 通道)
- [ ] 二维码 ≥ 2 in、可解码、每个有标签;链接尽量短

## F. 文本语义
- [ ] 控制词 / 模式名 / 方法名的语义色全文统一(如 /think 蓝、/no_think 绿)
- [ ] section 内加粗用黑,不用主题色(主题色只给 section 标题)
- [ ] 结论 bullet 先结论后数据,完整句;禁止 "[Put contents here]"、TBD、占位
- [ ] 作者/机构/标题与论文一致;无 rebuttal/修订叙事

## G. 文件
- [ ] `validate.py --original <模板>` PASS
- [ ] 图片资源嵌入(非链接);文件 < 50 MB
- [ ] commit 信息无 AI 署名尾注;版本号递增,旧版不删
